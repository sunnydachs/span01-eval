# Track A — 実データでの with/without (2026-09-27)

コーパス: 日本語ナレーション 211件（`*/story.json`）。うちラテン語トークンを含む=22件、
クリーン=189件から決定的に30件をサンプル。合計52件を採点。
実行: 52コール、エラー0、429なし、`cost=0` 全件、各 0.35–0.95s。

## 判定（gate v4, 閾値0.5）
- クリーン30件の誤検知 0（最大 0.048）
- ラテン語含有22件のうち **21件を検知**（0.529–0.953）
- 唯一の未検知: ラテン語ロール名を含む1件（確率 0.025）

## 3手法の比較（ラベル基準で見え方が変わる）

**(a) strict: ラテン語が出たら全て欠陥**
```

regex  22   0   0  30   1.000  1.000  1.000
gate   21   0   1  30   1.000  0.955  0.977
```

**(b) ラテン文字のキャラ名を許容（固有名詞の例外を認める）**

## 重要な注意
1. **strict の比較はほぼ自明（循環的）**。クリーンの30件は「ラテン語を含まない」と
   定義して抜き出した集合なので、ラテン語検出器なら何でも100%になる。
   このコーパスには「許容される英字」（ブランド名等）がほぼ無く、**弁別力は測れない**。
2. **固有名詞の除外は例示駆動で脆い**。指示文に載せた例（この実験では `Kuro`）しか
   除外されない。別の名前は検知側に倒れる（実コーパスのキャラ名は、指示文に載っていない
   ため全件検知された）。
3. 実データの混入はほぼ「隣接 or 空白区切り」型なので、**4行の regex で十分**。
   モデルの価値は「複数語の英語」と「誤検知を出さない」ことに限られる（Track C/D 参照）。
